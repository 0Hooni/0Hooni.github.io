# 실패 사례 누적

포스트를 작성하면서 실제로 발생한 실수와 해결 방법을 누적한다. 같은 실수를 반복하지 않는 것이 목적이다.

새로운 실수를 발견하면 증상, 원인, 해결의 세 부분으로 기록한다.

## 1. Mermaid 코드 블록이 일반 텍스트로 표시됨

- 증상: Mermaid 블록이 다이어그램이 아니라 코드 그대로 화면에 나타난다.
- 원인: Chirpy는 포스트 Front Matter에 `mermaid: true`가 있어야 `mermaid.js`를 로드한다.
- 해결: Front Matter에 `mermaid: true`를 추가한다.
- 참고: [`chirpy-theme.md`](chirpy-theme.md)

## 2. Mermaid 강조색이 다크 모드에서 너무 튐

- 증상: 강조 박스의 진한 채우기 색이 다크 모드에서 지나치게 눈에 띈다.
- 원인: 짙은 채우기 색은 어두운 배경에서 대비가 과하다. 기본 Mermaid 색도 다크 모드 톤과 맞지 않을 수 있다.
- 해결: `%%{init: {'theme':'neutral'}}%%` 헤더로 중성 테마를 적용한다. 강조는 채우기 대신 선의 굵기나 색으로 표현한다.

## 3. 서론에 흐름 목차표 작성

- 증상: 본문 시작 전에 단계와 핵심 질문을 담은 흐름표가 들어갔다.
- 원인: Chirpy의 사이드바 TOC와 내용이 중복된다.
- 해결: 표를 제거하고 연결 문장으로 첫 섹션에 자연스럽게 이어간다.
- 참고: [`user-preferences.md`](user-preferences.md)

## 4. 표에 긴 설명을 넣음

- 증상: 오해와 실제의 비교를 표로 만들었지만 셀이 길어 한눈에 들어오지 않는다.
- 원인: 표는 짧은 비교에 적합하며 한 셀이 길어지면 가독성이 떨어진다.
- 해결: 굵은 제목과 본문 단락 형식으로 풀어쓴다.
